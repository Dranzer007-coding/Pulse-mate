PULSE MATE — COMPLETE FRONTEND UI/UX SPECIFICATION
Version: 1.0
Purpose: Frontend implementation blueprint for the Pulse Mate health companion platform.

============================================================
1. PRODUCT VISION
============================================================

Pulse Mate is a mobile-first personal health companion that connects wearable/device data with a health intelligence app. It continuously organizes health, activity, environmental and wellness signals into understandable insights, early warnings, recommendations and emergency support.

The frontend should feel like a premium health-tech product: modern, trustworthy, slightly futuristic, visually rich, but never like a medical hospital dashboard.

Primary visual references:
- Premium smartwatch + health dashboard applications
- Dark purple/blue/teal health cards
- Soft gradients and subtle glow
- Rounded cards
- Clean charts
- Large readable numbers
- Strong visual hierarchy
- Minimal clutter
- Mobile-first PWA
- Accessibility-friendly typography and contrast

Important product principle:
Pulse Mate should NOT present AI predictions as confirmed medical diagnoses. Use language such as:
"Potential risk detected", "Pattern worth checking", "Consider consulting a doctor", and "Emergency assistance recommended".

3. DESIGN SYSTEM
============================================================

Color direction:
- Primary: electric blue / cyan
- Secondary: deep purple
- Accent: teal/green for healthy states
- Warning: amber/orange
- Critical: red
- Background: near-black / deep navy
- Cards: dark navy/purple with subtle elevation
- Light mode may use white/off-white cards with blue/purple accents

Typography:
- Large bold numbers for vitals
- Medium-weight section titles
- Small muted metadata
- Avoid excessive uppercase text

Cards:
- Border radius: 18–26px
- Subtle shadow/glow
- Internal spacing: generous
- Icons inside circular colored containers

Charts:
- Line charts for trends
- Bar charts for daily activity
- Circular progress rings for scores
- Heatmaps for time-based patterns
- Sparkline charts inside health cards

Health status indicators:
Green = Stable
Yellow = Monitor
Orange = Attention
Red = Urgent

Use icons consistently for:
Heart, lungs, thermometer, droplet, footsteps, moon, battery, shield, warning, ambulance, medicine, location, doctor, cloud/weather, air quality.

40. RECOMMENDED FRONTEND TECH STACK
============================================================

Core:
- React
- Vite
- TypeScript or JavaScript

Styling:
- Tailwind CSS or modular CSS
- Framer Motion for subtle animations

Charts:
- Recharts
or
- Chart.js

Icons:
- Lucide React

Maps:
- Mapbox or Google Maps depending on project requirements

PWA:
- Vite PWA plugin
- Service Worker
- IndexedDB/local storage for offline data

Device communication:
- Android Bluetooth APIs / native bridge where needed
- Web Bluetooth only where browser/device compatibility permits

Health platform integrations:
- Android Health Connect should be preferred where supported
- Other vendor APIs/SDKs where available

Backend:
- Node.js
- Express
- PostgreSQL / Supabase

Authentication:
- Firebase Auth or Supabase Auth

Notifications:
- Firebase Cloud Messaging

AI:
- On-device model where feasible
- TensorFlow Lite / LiteRT or ONNX Runtime Mobile
- Cloud AI only for non-sensitive/optional workloads
